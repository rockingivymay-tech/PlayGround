# PlayGround

## Sizzle — a cozy cooking simulator

Sizzle is a touch-first cooking game for phones and tablets. There are no clocks,
no countdowns, and no way to lose. Pick a recipe, heat the pan, add ingredients,
stir, and serve whenever it looks right.

### Play

Serve the folder with any static file server, then open `index.html`:

```bash
python3 -m http.server 3002
```

### Controls

- **Tap** an ingredient, then tap the pan. You can also drag an ingredient onto the pan.
- **Drag** the heat gauge to find a gentle or sizzling temperature.
- **Hold Stir** (or swipe in the pan) to keep everything moving.
- **Tilt** is optional. On iOS, Sizzle asks for motion permission when you enable it.
- **Serve** unlocks once every recipe ingredient is in the pan. Low doneness still
  serves — it just scores lower.

Three recipes cycle in order: Sunny Omelette, Tomato Basil Pasta, and Garden
Stir-fry. Tips are saved locally, and the recipe card is available from the pill in
the top bar on smaller screens.

Built with plain HTML, CSS, and Canvas 2D. No build step, libraries, or external
assets.
